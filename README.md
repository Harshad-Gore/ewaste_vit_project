
# E-Waste VIT Project

This repository contains code and resources for the E-Waste VIT Project, which focuses on the classification, clustering, and evaluation of e-waste data using machine learning and deep learning techniques.

## Project Structure

- `agent/` - Contains agent scripts and tools for automation and data processing.
- `dashboard/` - Dashboard application for visualization and interaction.
- `data/` - Datasets (raw, processed, augmented) used in the project.
- `evaluation/` - Evaluation metrics and scripts.
- `models/` - Trained models, results, and model-specific resources.
- `notebooks/` - Jupyter notebooks for data preparation, training, clustering, and evaluation.
- `paper/` - Project documentation and research paper materials.

## Getting Started

1. **Clone the repository:**
	```bash
	git clone <repo-url>
	cd ewaste_vit_project
	```

2. **Set up a Python virtual environment:**
	```bash
	python -m venv .venv
	source .venv/bin/activate  # On Windows: .venv\Scripts\activate
	```

3. **Install dependencies:**
	```bash
	pip install -r requirements.txt
	```

4. **Explore the notebooks:**
	Open the `notebooks/` directory and run the Jupyter notebooks for data analysis, model training, and evaluation.
